React Router application aimed at the My eduID personal and security pages. It loads `/config` and otherwise shows a placeholder. It is not a Maven module and it is not the self-service application that ships today. The Svelte My eduID app is the deployed UI. This container stays a draft because the TypeScript scanner never matches it.
